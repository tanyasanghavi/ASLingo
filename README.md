# ASLingo

Learn sign language with a 3D wizard coach. The camera watches your hands and face and gives live feedback.

## Run it

```bash
npm install
npm run dev
```

## Roadmap

1. Scaffold, theme, 3D wizard, sign in (mock), questions, learning-path home (done)
2. Real auth + cloud database (Firebase)
3. Lesson player with camera + MediaPipe hand tracking and scoring
4. Facial expression tracking + Gemini live coach
5. Progress page
6. Solo games + leaderboard
7. Sign Battles + teams
